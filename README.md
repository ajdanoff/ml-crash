# Machine Learning Crash Course Models in Python

This repository contains implementations of various machine learning models in Python, inspired by and aligned with the concepts and exercises from the [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course/).

## Overview

The Google Machine Learning Crash Course is a free, comprehensive introduction to machine learning, covering foundational topics such as linear regression, logistic regression, classification, neural networks, and large language models. This repository serves as a practical complement to the course by providing clean, readable Python code examples illustrating these fundamental ML techniques.

## Contents

The repository includes Python scripts and notebooks implementing models and concepts such as:

- Linear Regression with gradient descent and hyperparameter tuning
- Logistic Regression for binary classification tasks
- Classification evaluation metrics (accuracy, precision, recall, AUC)
- Handling numerical and categorical data preprocessing
- Introduction to neural networks including perceptrons and activation functions
- Basic implementation of large language model concepts
- Techniques for working with datasets, preventing overfitting, and ensuring generalization

## Purpose

This repository helps learners reinforce their understanding of machine learning by experimentation with code examples. It is useful for those who prefer hands-on learning and want to see how theoretical concepts translate into working Python code with popular libraries.

## How to Use

1. Clone this repository:

git clone https://github.com/ajdanoff/ml-crash.git
cd ml-crash


2. Follow along with the [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) lessons.

3. Run the scripts or notebooks to see practical implementations.

4. Modify and experiment with the code to deepen your understanding.

## Requirements

- Python 3.8+
- NumPy
- pandas
- scikit-learn
- Matplotlib (optional for plotting)

Install dependencies with:

pip install numpy pandas scikit-learn matplotlib
